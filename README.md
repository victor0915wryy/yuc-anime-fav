# yuc-anime-fav
專為長門番堂 (yuc.wiki) 打造的油猴腳本（Tampermonkey Script），一個簡易本地追番收藏夾。  

一鍵追番收藏：在番劇標題旁注入「☆」按鈕，點擊即可加入追番清單。

懸浮管理面板：浮窗按季度顯示追番列表

繁簡文本轉換：面板內建繁簡切換功能

資料備份功能：新增匯出與匯入備份功能


使用方法

- 打開 `yuc-fav.user.js`，複製全部內容
- 在 Tampermonkey / Violentmonkey 中新增一個腳本，把複製的內容全部貼上並儲存。
- 打開 yuc.wiki 任一季新番頁面，即可在標題旁看到「☆」按鈕，右側也會出現「追番列表」懸浮按鈕。
